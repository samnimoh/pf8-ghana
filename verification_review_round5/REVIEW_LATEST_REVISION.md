**Confirmed remaining findings**

1. **[P2] The final calibration still receives contradictory qualifications.** In the [main record](/Users/samnimoh/Desktop/chromo/Pf8_Ghana_manuscript_REVISED.docx), §5.6, PDF page 79, the live caveat says “because proper matching lowers the threshold, the reported threshold is the conservative one and matching would admit more outliers, not fewer.” However, the corrected §5.7.4, page 90, explicitly says the experiment on the superseded panel does not establish the direction of error for the final run. The [supplement](/Users/samnimoh/Desktop/chromo/article/Additional_file_1.docx), pages 80 and 91, repeats the contradiction. Propagate the accurate qualification into §5.6: frequency matching remains a limitation, and its effect on the final threshold is not established by the archived evidence. The stale-PDF explanation no longer applies; both current sources contain the contradiction.

2. **[P2] Robust low differentiation is still promoted to an established mating conclusion.** Main §3.14, page 60, says “Near-panmixia, by contrast, is robust, and this strengthens it”; §10.1, page 163, says its survival is the strongest evidence the analysis holds. Supplement counterparts are pages 61 and 164. These are live conclusions, not historical quotations. Threshold stability supports stability of the measured common-variant differentiation. It does not by itself estimate random mating or contemporary exchange. The short article already uses the more defensible framing. Carry that framing throughout the record and supplement: “Very low, detectable common-variant differentiation is stable across the tested thresholds.” This criticism does not mean small nonzero FST demonstrates strong subdivision or alone disproves approximate panmixia. The server-matched [pairwise estimates](/Users/samnimoh/Desktop/chromo/corrected/final_fst_pairwise.csv) and [sensitivity results](/Users/samnimoh/Desktop/chromo/corrected/sensitivity_summary.csv) remain intact. The interpretation follows the distinction between an allele-frequency statistic and the processes contributing to it discussed by [Holsinger and Weir](https://www.nature.com/articles/nrg2611).

3. **[P2] The TreeMix interpretation correction is incomplete.** Main §6.7, page 109, still says “What the graph establishes is that a strictly bifurcating tree does not describe these populations” and associates this with ongoing exchange. Supplement page 110 does the same. The subsequent statement correctly limits edge evidence to the selected graph, but does not qualify that preceding assertion. My review judgment is that the graph should be described as a conditional covariance-model fit unless additional evidence supports a broader historical inference. The [original TreeMix paper](https://journals.plos.org/plosgenetics/article?id=10.1371/journal.pgen.1002967) explains that edge significance is conditional on a fixed graph and does not incorporate graph-structure errors. This finding does not dispute the saved edge statistics.

4. **[P2] Guaranteed FDR control survives in a summary.** Main §5.7.4, page 90, says the rerun “replaced an uncorrected quantile with an FDR-controlled list”; supplement page 91 repeats it. That wording overstates what the newly conditional §6.8.1 counts establish. Describe a list selected using BH q-values against the simulated null, with control conditional on adequate calibration. The correction to the counts is real; the qualification needs to reach the summary too.

5. **[P2/P3] Verification notes need scope corrections and explicit supersession.** [VERIFICATION_NOTES.md](/Users/samnimoh/Desktop/chromo/provenance_final/VERIFICATION_NOTES.md) is byte-for-byte unchanged from the last review. Its early TreeMix section retains the “underflow” explanation, exact-reproduction language and a categorical generating-command conclusion. Its later Numerics section correctly withdraws or narrows these statements. Mark the earlier account as superseded, or reconcile it with the later explanation; this is a correction-record clarity defect, not evidence that the latest numerical analysis was never corrected. Separately, the heading “confirmed genuine at read level” exceeds a check of stored genotype and quality fields, and the absence of an `X` in the panel output is not independent validation of that same reconstruction. Align these statements with the narrower evidence scope already recognized in the audit README and main record.

6. **[P3] Four supplementary captions retain obsolete numbering explanations.** Tables S10 and S13 still explain numbering “after” another table; S24 and S28 say they are “lettered.” The labels themselves are correct. Remove those obsolete explanations. I independently checked the article’s sensitivity reference to Table S13 and found no broken target there.

7. **[P2] The new document tools are not yet portable or safe against partial writes.** [build_article.py](/Users/samnimoh/Desktop/chromo/tools/build_article.py:7) hardcodes its reference input to an external temporary directory. That file exists on this machine, and independent scratch rebuilds reproduced the current article and supplement paragraph texts. Those successes do not show that the repository alone rebuilds the article elsewhere. Archive and parameterize the reference input. The article builder also deletes its destination before ZIP writing finishes: a scratch test injecting a write failure destroyed the original sentinel and left an empty archive. [apply_edits.py](/Users/samnimoh/Desktop/chromo/tools/apply_edits.py:53) requires `concept` and `sev`, although its README documents only `quote` and `repl`. Synthetic tests further showed that a valid edit plus an unmatched edit returns success and writes a partial result, and a duplicated quote silently changes only the first occurrence. Reconcile the documented schema, enforce occurrence expectations and abort before writing on any failure; stage the archive replacement before replacing a deliverable. These findings concern the helpers and their README promises, not evidence that a current manuscript was damaged. See [synthetic test evidence](/Users/samnimoh/Desktop/chromo/verification_review_round5/build_tools_validation.json) and [independent build evidence](/Users/samnimoh/Desktop/chromo/verification_review_round5/independent_build_review.json).

**Confirmed scope and evidence gaps**

Git is a useful improvement. Baseline `3f0130d` contains 8,084 files; the combined scientific correction `e590ba7` contains 8,086. Ten affected baseline identities match the preceding review. This is one combined correction commit, rather than a separate commit for each finding. During this review, `1afaf4b` added project instructions, document tools and preliminary review artifacts, bringing the tracked count to 8,123. The final report and evidence were completed afterward. Git now preserves these states; it does not reconstruct historical generating lineage for earlier outputs.

The newly archived server script has `--samples` and `--suffix`, and its current print statements include the suffix. Its modification time is later than the saved run log, so it should not be presented as a verified hash of the historical generating revision. The cohort log and output identity are now independently checked; exact generating command, complete input identities and final calibration inputs remain incomplete. This is an evidence gap, not a new numerical error.

The existing [Lean validation](/Users/samnimoh/Desktop/chromo/verification_audit/lean_validation.json) and [proof source](/Users/samnimoh/Desktop/chromo/verification_audit/Pf8Audit.lean) are unchanged. The recorded Lean 4.19.0 build covers 16 reference theorems. It does not prove that the executable Python pipeline implements those specifications, or establish source-data correctness, calibration adequacy or the manuscript’s biological interpretations. No new implementation proof or Lean validation is present in the reviewed correction.

The article still requires authors and affiliations, its burden citation, funding and contribution statements, a repository DOI/deposit, and resolution of the geographical layer’s source and licence. These remain submission-readiness items. No new evidence in the reviewed correction closes them.

**What this review could not certify**

The review checked document claims, saved aggregates, server identities, correction propagation, Git snapshots and PDF text synchronization. It did not rerun dimensionality reduction or other scientific analyses, inspect raw read alignments, reconstruct missing final calibration inputs, or certify the pipeline end to end. Thirty-six targeted assertions passed; several deliberately confirm the presence of a remaining defect. Their passing is not a scientific-validity certificate.
